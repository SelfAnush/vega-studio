# Keyboard shortcuts

Shortcuts never intercept typing in inputs, textareas, selects,
contenteditable controls, dialogs, or menus. `Ctrl` below also works as
`Cmd` on macOS.

| Shortcut | Action |
| --- | --- |
| Ctrl/Cmd+Z · Ctrl/Cmd+Shift+Z · Ctrl/Cmd+Y | Undo · redo |
| Ctrl/Cmd+C · Ctrl/Cmd+V | Copy · paste selected layers |
| Ctrl/Cmd+D | Duplicate selection |
| Ctrl/Cmd+G · Ctrl/Cmd+Shift+G | Group · ungroup |
| Ctrl/Cmd+S | Save project file |
| Delete / Backspace | Delete selection |
| Arrow keys (Shift = 10 px) | Nudge selection |
| V / H | Select tool / permanent hand tool |
| Alt (hold) | Temporary hand: drag to pan, release to resume |
| Space (hold) | Temporary hand fallback (same as Alt) |
| Ctrl/Cmd+wheel over canvas | Zoom around the pointer |
| Escape | Cancel gesture / close menu / clear selection |

Alt-to-pan is the requested Studio behavior; no claim is made about
matching any other application's exact default mapping. Space exists only
as an equivalent fallback and never activates focused buttons or inputs.
