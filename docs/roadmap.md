# Roadmap

Checked items are implemented; unchecked items are planned or still need verification.

- [x] Text, rectangles, ellipses, and lines.
- [x] Horizontal and vertical bar charts with labels, tooltips, and thresholds.
- [x] Layers, nested groups, multiselection, alignment, and locking.
- [x] Drag, resize, copy, paste, and duplicate.
- [x] Undo and redo.
- [x] Zoom, pan, grid, and snapping.
- [x] Shared datasets, data bindings, conditional colors, and visibility rules.
- [x] JSON data editing and source drafts.
- [x] Elasticsearch query configuration, fixture preview, and export.
- [x] Project save/open and migration from older file formats.
- [x] Vega export with validation, copy, and download.
- [x] Searchable element library and adjustable Properties panel.
- [x] Light and dark themes.
- [x] Five editable example projects.
- [ ] Verify exports in a live Kibana dashboard.
- [ ] Responsive dashboards and mobile editing.
- [ ] Verify Firefox, Safari, and touch support.
- [ ] Autosave and project recovery.
- [ ] Automatic text wrapping and better handling of overlapping chart labels.
- [ ] Reduce the production bundle size.
- [ ] Complete screen-reader and accessibility testing.
- [ ] KPI / metric cards.
- [ ] Progress bars.
- [ ] Status indicators.
- [ ] Images and logos.
- [ ] Line charts.
- [ ] Area charts.
- [ ] Donut charts.
- [ ] Gauges.
- [ ] Tables.
- [ ] Scatter plots.
- [ ] Heatmaps.
- [ ] Repeated cards or rows driven by data.
- [ ] Reusable components and templates.
- [ ] Advanced data transformations and aggregation.
- [ ] Import existing Vega specifications.
- [ ] Live data connections.
- [ ] Collaboration and hosted accounts.
