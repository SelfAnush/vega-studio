# v1.1.0 implementation plan — elements and visual configuration

> Release note: this scope shipped as part of application `1.2.0` (see
> `CHANGELOG.md`). The plan below is preserved as written.

- Target application release: **v1.1.0** (minor: backward-compatible features).
- Schema decision: project document schema **3** (already migrated in-tree;
  v1/v2 open via default filling; no further format change for this release).
- Status: **Complete** — implemented and verified in the working tree;
  unreleased (`package.json` still `1.0.0`, no tag). Evidence:
  `docs/completion-2a.md`.

## Goal

Make the element library and property inspector substantially more
useful. Priority: configurable elements that export faithfully to Vega.
Elasticsearch integration is explicitly later work.

## Included scope

1. Enhanced text (font families, size/weight, alignment, placement, line
   height, multiline, color, opacity, defined clipping overflow).
2. Enhanced rectangles (optional stroke/width/dash, solid-or-none fill,
   opacity, corner radius).
3. Ellipse/circle (independent dimensions, aspect lock, native Vega
   `path`).
4. Line (editable endpoints incl. zero width/height, caps, dashes,
   handles, exact numeric editing, group-safe local coordinates).
5. Bar charts: orientation, padding, spacing, axes/grid/ticks/maximum,
   bindings, per-chart sorting without mutating shared rows, label
   placement, number/percent/bytes formats, decimals, tooltips,
   single/threshold colors, generated legend.
6. Composition: categorized palette, sectioned inspector, multiselect,
   group/ungroup, 6-way align, distribute (3+), guides, grid snap,
   one-step undo, Escape cancel.
7. Local synthetic fixtures + three editable examples; provenance in
   `docs/sample-data.md`.
8. Docs: schema/migration notes, element matrix, compatibility notes,
   completion report. Full configuration reference: `docs/elements.md`.

## Excluded scope (verified absent from `src/`)

Gauges, KPI cards, donut charts, heatmaps, images, icons, reusable
component systems, Elasticsearch queries/connections, backend services,
accounts, collaboration, AI generation, arbitrary Vega import, separate
chart engine, responsive layout, production deployment.

## Dependencies

Pinned `vega@6.2.0`; Kibana `9.2.3` compatibility target; no new runtime
dependencies (none added).

## Acceptance criteria (all met; evidence in `docs/completion-2a.md`)

- [x] v1/v2 projects migrate to schema 3 with equivalent visuals.
- [x] New properties round-trip through save/open.
- [x] Ellipse dimensions and horizontal/vertical/degenerate-line validation.
- [x] Text alignment + multiline export; both bar orientations render.
