# Vega Studio v1.2.0

Vega Studio is a browser-based visual designer for Vega dashboards and Kibana
panels. No account, backend, or live Elasticsearch connection is
required to design and preview a panel.

## Included

- Styled text, rectangles, ellipses, lines, and horizontal/vertical bar charts.
- Nested groups, layers, locks, multiselection, alignment, and distribution.
- Direct drag/resize, copy/paste, undo/redo, zoom, pan, grid, and snapping.
- Named datasets, field/reduction bindings, conditional colors, numeric mappings,
  and visibility conditions.
- Inline Vega export and Elasticsearch Query DSL export with response fixtures.
- Validated project save/open and migration from project schemas 1–3 to schema 4.
- Searchable element library, vertical Properties, light/dark themes, keyboard
  export tabs, and source drafts retained while the data dialog is open.
- Five editable synthetic examples, MIT license, and third-party notices.

## Get started

Use Node.js 22.12 or newer (verified with 22.22.2):

```sh
git clone https://github.com/SelfAnush/vega-studio.git
cd vega-studio
npm ci
npm run dev
```

Open `http://127.0.0.1:5173`. Production builds use `npm run build`; preview
with `npm run preview`. See the [README](https://github.com/SelfAnush/vega-studio#readme).

## Validation and limits

Automated validation covers 112 unit tests, 31 browser tests, and four production
workflow tests. Chromium UI checks cover both themes at 1024, 1366, and 1920px.

- Desktop authoring requires at least 1024px width; exports use fixed dimensions.
- Live Kibana behavior is unverified. Elasticsearch export generates configuration;
  Studio previews fixtures and does not query a cluster.
- Firefox, Safari, mobile authoring, and a full accessibility audit are unverified.
- No autosave/recovery, automatic text wrapping, or arbitrary Vega import.
- The production build has an approximately 1.3 MB JavaScript bundle advisory.
- KPI, progress, status, image, and additional chart elements remain planned.

See the [roadmap](https://github.com/SelfAnush/vega-studio/blob/main/docs/roadmap.md)
for completed, partial, and planned work.
