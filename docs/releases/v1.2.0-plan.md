# v1.2.0 implementation plan — editor interaction & data-driven elements

- Target application release: **v1.2.0** (minor: backward-compatible features).
- Schema decision: project document schema **4** (named sources, bindings,
  visibility; migration from versions 1–3 included).
- Status: **Complete** — implemented and verified in the working tree;
  unreleased as a tag/publication (`package.json` declares `1.2.0`, no tag
  exists). Evidence: `docs/completion-1.2.0.md`.

## Goal

Correct the editing experience and make every element capable of
displaying or responding to data, with Elasticsearch-ready export that
keeps Studio local.

## Included scope

1. Full-window layout at 100% zoom (welcome + editor fit, internal panel
   scrolling, fitting dialogs).
2. Live direct manipulation (transient previews, no per-move Vega
   rebuild) and palette drag-to-create with placement ghost.
3. Copy/paste with versioned payload, subtrees, id remap, cascade,
   one-step undo, explicit dataset handling.
4. Complete threshold legends (all states, settings-derived units,
   row-packed layout, both orientations, minimum size).
5. Theme-token selection styling; overlays excluded from export.
6. Pointer-anchored Ctrl/Cmd+wheel zoom; Alt/Space temporary hand.
7. Custom grid (show/snap/spacing 1–200 px, separate guide toggle) as
   editor settings; guides-beat-grid precedence.
8. Eight resize handles with aspect control, minimums, no flipping, group
   proportional scaling; endpoint handles for lines.
9. Shared binding model (fixed / field / reduction: match, latest,
   count/sum/average/min/max) with defined missing-data semantics;
   conditional color rules; bounded numeric mappings; data-driven
   visibility — all compiled to Vega.
10. Named datasets; Query DSL export (`%context%`, `%timefield%`,
    `format.property`); response fixtures; dual export choices with
    explicit blockers. No live connections, credentials, or backend.
11. Reactive example; shortcuts guide; binding docs; schema/migration
    notes; compatibility notes.

## Excluded scope (verified absent where behavioral)

New chart types (moved to v1.3.0), dashboard components (v1.4.0),
reusable component systems, live Elasticsearch connections or cluster
credentials, backends, accounts, collaboration, AI generation, arbitrary
Vega import, separate chart engine, responsive layout, deployment,
release tags, package publication.

## Dependencies

Pinned `vega@6.2.0`; Kibana `9.2.3` target; no new runtime dependencies
(no dependency changes at all — only the version metadata bump).

- [x] Drop/move coordinates correct; committed art matches previews.
- [x] Copy/paste incl. groups and bindings; one-step undo; locks refuse.
